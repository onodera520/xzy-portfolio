# 作品集 StaggeredMenu 左侧导航设计

## 目标

将页面左上角现有三道短线控件改造成全站侧栏触发器。侧栏从左侧分层滑入，同时提供首页板块导航和项目快捷入口，帮助招聘者快速理解作品集结构并在案例之间切换。

## 信息结构

所有双语分组标题和中文子项同时显示，不使用二次展开。

- `HOME / 首页`
  - 作品集首屏：`/#top`
- `ABOUT / 关于`
  - 个人介绍：`/#about`
  - 求职方向与能力：`/#about-details`，为现有能力信息增加独立锚点
- `PROJECTS / 作品`
  - AI 健康管家一站式服务平台：`/work/consumer`
  - 跨境电商异常中枢平台：`/work/enterprise`
  - 骑福兽，闹新春：`/work/campaign`
  - AI 产品探索 · 即将上线：禁用状态，不生成链接
- `PROCESS / 过程`
  - 设计过程与 AI：`/#process`
- `LAB / 实验`
  - 设计决策实验室：`/#lab`
- `CONTACT / 联系`
  - 联系方式与简历：`/#contact`

菜单底部显示静态状态文字 `OPEN TO WORK · UI/UX · AI PRODUCT`，不展示没有真实地址的社交链接。

## 视觉

- 面板从左侧出现，桌面端宽度约 `clamp(480px, 42vw, 560px)`，手机端占满视口。
- 分层滑出颜色仅使用现有中性主题：墨黑 `#0B0B0B`、炭灰 `#454541`、暖灰 `#C8C6BF`；主面板为暖白 `#F7F6F2`。
- 不使用荧光绿或其他高饱和色。
- 双语分组标题为主要层级，中文子项使用更小字号与中灰文字。
- 悬停和键盘焦点使用黑色、浅灰底或细下划线表达，不使用彩色高亮。
- 桌面端鼠标悬停或键盘聚焦双语分组标题时，标题左侧复用现有透明小蜜蜂 `/hero/design-in-bloom/bee.png`，从轻微左移与透明状态渐显；中文子项不显示蜜蜂。
- 小蜜蜂作为无语义装饰，尺寸约 `32–44px`、低透明度、不可点击且不影响标题布局。触屏设备不强制显示该装饰。
- 首页关闭状态的触发器继承当前黑色导航；深色案例页继承白色导航。菜单打开后触发器统一变为黑色。

## 交互

- 点击左上角三道短线控件打开菜单，控件在打开状态转为关闭形态。
- 黑、灰、暖灰三层依次滑入，再显示暖白主面板；分组及子项逐组错峰进入。
- 点击有效链接、点击菜单外部或按 `Escape` 关闭菜单。
- 打开菜单时锁定页面滚动，并将焦点移入菜单；关闭后焦点返回触发器。
- 桌面端保留顶部 PillNav，侧栏承担完整索引功能。
- 手机端隐藏 PillNav 自带菜单，仅保留左上角 StaggeredMenu，避免重复导航入口。
- AI 产品探索以禁用视觉呈现，并明确标注“即将上线”。
- 分组标题的蜜蜂装饰与菜单项进入动画相互独立；反复悬停不会重新触发整个侧栏时间线。

## 组件结构

- 新增独立 `StaggeredMenu` 组件和 CSS，基于用户提供的 React Bits JavaScript + CSS 源码，复用项目现有 GSAP。
- 新增集中式菜单数据，分组项包含双语标题、中文子项、链接和禁用状态。
- `Navigation` 继续负责顶部导航布局，并将左上角触发位置交给 `StaggeredMenu`。
- 首页与所有案例路由复用同一份菜单内容；链接均使用当前 Vite 单页路由兼容的 URL。

## 验证

- 首页、C 端、B 端和 H5 路由均包含同一侧栏触发器和完整分组。
- 所有有效子项具有正确链接，AI 产品项不可点击。
- 打开、关闭、点击外部、`Escape`、滚动锁定和焦点恢复均可用。
- 桌面端 PillNav 保留，手机端不出现重复菜单按钮。
- 颜色只包含指定黑灰暖白值，侧栏代码不存在荧光绿 `#b8ff68`。
- 双语分组标题悬停和键盘聚焦时显示现有透明蜜蜂素材，子项和触屏默认状态不显示。
- `npm test` 与 `npm run build` 零失败。

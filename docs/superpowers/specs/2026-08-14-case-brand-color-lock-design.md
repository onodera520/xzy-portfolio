# 作品详情页品牌颜色锁定设计

## 目标

所有作品详情页中的左上菜单按钮与“XUE STUDIO”在页面滚动期间始终保持黑色，不再根据当前作品图片的明暗切换成白色。

## 范围

- 适用于 C 端、B 端和 H5 等所有使用 `.board-case` 容器的作品详情页。
- 只固定左上 `.nav-brand` 区域的颜色，包括菜单触发按钮和“XUE STUDIO”文字。
- 首页及其他非作品详情页继续保留现有的明暗对比度自适应行为。
- 不修改中间导航胶囊、右侧图标、章节导航、作品图片、滚动动画或菜单交互。

## 实现方式

在作品详情页作用域中覆盖品牌区的颜色变量，使 `.board-case .nav-brand` 以及滚动产生的 `data-brand-contrast="dark"` 状态都使用 `var(--bloom-ink)`。保留现有对比度检测逻辑，避免影响其他页面。

## 验证

- 增加样式回归测试，证明普通状态与 `data-brand-contrast="dark"` 状态下，作品详情页品牌区都固定为深色。
- 运行完整测试与生产构建。
- 确认首页动态品牌对比度相关测试仍然通过。

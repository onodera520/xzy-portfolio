# 作品详情页品牌颜色锁定设计

## 目标

所有作品详情页中的左上菜单按钮与“XUE STUDIO”在页面滚动期间始终保持黑色，不再根据当前作品图片的明暗切换成白色。

## 范围

- 适用于 C 端、B 端和 H5 等所有使用 `.board-case` 容器的作品详情页。
- 只固定左上 `.nav-brand` 区域的颜色，包括菜单触发按钮和“XUE STUDIO”文字。
- 首页及其他非作品详情页继续保留现有的明暗对比度自适应行为。
- 不修改中间导航胶囊、右侧图标、章节导航、作品图片、滚动动画或菜单交互。

## 实现方式

为导航组件增加可选的固定对比度参数。作品详情页传入 `light`，使左上品牌区即使检测到深色作品图片也继续输出深色文字；首页不传该参数，继续使用现有的动态检测结果。导航同时声明 `data-brand-contrast-mode`，用于区分固定与自适应模式。

## 验证

- 增加对比度解析测试，证明固定值会覆盖滚动检测结果，而未固定时仍返回检测结果。
- 增加路由渲染测试，证明作品详情页使用固定模式，首页使用自适应模式。
- 运行完整测试与生产构建。
- 确认首页动态品牌对比度相关测试仍然通过。

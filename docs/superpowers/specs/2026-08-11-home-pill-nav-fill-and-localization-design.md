# 首页胶囊导航填充与中文化设计

## 目标

修复首页导航中短标签按钮（目前表现为 ABOUT、LAB）悬停后黑色圆形未完全覆盖胶囊的问题，并将五个导航标签统一改为中文。

## 交互基准

- 以当前 PROJECTS 按钮的黑色扩散效果为唯一视觉与动效基准。
- ABOUT、LAB 等短按钮不新增独立动画，不改变节奏、缓动、方向或文字切换方式。
- 所有按钮继续使用同一套 `PillNav` 结构和 GSAP 时间线。
- 修正覆盖几何，使短按钮在动画结束时与 PROJECTS 一样完整填满胶囊，不露出白色边缘。
- 默认状态保持浅色/透明底与黑字；悬停状态为完整黑底与白字。

## 中文标签

导航按现有顺序改为：

1. 关于
2. 作品
3. 过程
4. 互动实验
5. 联系

桌面导航和手机菜单共用同一数据源，因此同步显示中文。锚点地址保持 `#about`、`#work`、`#process`、`#lab`、`#contact` 不变。

## 范围

- 不修改 Logo、侧边菜单、CV、邮箱按钮、页面章节内容或路由。
- 不新增依赖，不重构无关导航组件。
- 保持键盘焦点、触摸设备处理和减少动态效果设置。

## 验证

- 添加回归测试，确认五个中文标签及原锚点顺序。
- 添加覆盖几何测试，确认短按钮采用与 PROJECTS 一致且足够的最终覆盖范围。
- 在首页依次检查短标签和长标签悬停结束状态。
- 检查桌面与手机菜单无横向溢出。
- 运行完整测试和生产构建。

# 首页胶囊导航填充与中文化设计

## 目标

修复首页导航中短标签按钮（目前表现为 ABOUT、LAB）悬停后黑色圆形未完全覆盖胶囊的问题，并将五个导航标签统一改为中文。

## 交互基准

- 以用户提供的 React Bits PillNav JavaScript + CSS 原版为唯一视觉与动效基准。
- 所有按钮统一从 `scale: 0` 扩散到 `scale: 1.2`，进入与退出分别为 0.3 秒和 0.2 秒。
- 所有按钮继续使用同一套 `PillNav` 结构和 GSAP 时间线，不保留首页专属 Apple 动效分支。
- 默认状态为白色胶囊与黑字；悬停状态为完整黑底与白字，黑色必须覆盖到胶囊最外沿。
- 保留参考组件的黑色导航底座，但不加入参考组件左侧的 logo/icon。

## 中文标签

导航按现有顺序改为：

1. 关于
2. 作品
3. 过程
4. 互动实验
5. 联系

桌面导航和手机菜单共用同一数据源，因此同步显示中文。锚点地址保持 `#about`、`#work`、`#process`、`#lab`、`#contact` 不变。

## 范围

- 不修改网站现有 XUE STUDIO 品牌区、侧边菜单、CV、邮箱按钮、页面章节内容或路由；“不加入左侧 icon”特指 PillNav 组件内部不渲染参考源码中的 `.pill-logo`。
- 不新增依赖，不重构无关导航组件。
- 保持键盘焦点、触摸设备处理和减少动态效果设置。

## 验证

- 添加回归测试，确认五个中文标签及原锚点顺序。
- 添加组件测试，确认使用标准黑色底座、白色胶囊配色且 PillNav 内没有 logo/icon。
- 在首页依次检查短标签和长标签悬停结束状态。
- 检查桌面与手机菜单无横向溢出。
- 运行完整测试和生产构建。

# 首页整体长胶囊导航设计

## 目标

将当前五个独立白色胶囊改为一个统一的白色长胶囊导航。每个导航项在默认状态下透明，仅在鼠标悬停或键盘聚焦时以现有 React Bits 圆形扩散动效填充为黑色；移开或失焦后恢复透明。作品详情页不显示常驻选中态或底部小黑点。

## 桌面外观

- `.pill-nav-desktop` 作为唯一的白色长胶囊容器，包含五个导航项。
- 容器使用完整圆角和轻微灰色边界，内部保留紧凑留白。
- `.pill` 默认背景透明、文字黑色，不再形成五个独立白色胶囊。
- 导航项之间不增加分割线，整体视觉以长胶囊轮廓统一。
- 中文标签、顺序、字号和锚点不变：关于、作品、过程、互动实验、联系。

## 交互状态

- 延续现有 `PillNav` 的 GSAP 圆形扩散逻辑：黑色圆形从 `scale: 0` 扩散到 `scale: 1.2`。
- 悬停或键盘聚焦时，当前项完整变黑且文字变白。
- 鼠标移开或失焦后，当前项恢复透明和黑色文字。
- 不设置常驻黑色项目。
- 删除 `.pill.is-active::after` 产生的底部黑点；详情页即使传入 `activeHref`，也不展示视觉选中标记。
- 保留按下时的轻微缩放、触摸设备判断和减少动态效果支持。

## 范围

- 仅修改桌面 PillNav 的外观和 active 视觉反馈。
- 不修改 XUE STUDIO 品牌区、侧边菜单、CV、邮箱按钮、页面路由、导航链接或页面内容。
- 手机端仍沿用当前折叠菜单，不改变结构和交互。
- 不新增依赖，不重构无关组件。
- 保留工作区内所有既有未提交修改。

## 验收

- 首页和作品详情页均显示一个白色长胶囊容器，而不是五个独立白色胶囊。
- 五个项目默认透明；悬停后黑色完整填充当前项目，移开后恢复透明。
- 作品详情页“作品”下方不再出现黑点，也没有常驻黑色状态。
- 键盘聚焦能够触发与悬停相同的高对比反馈。
- 390px 手机宽度下保持当前移动导航，无横向溢出。
- 自动化测试和生产构建无失败，浏览器控制台无错误。

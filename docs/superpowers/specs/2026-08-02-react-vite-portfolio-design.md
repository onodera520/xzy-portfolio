# Demo XZY React + Vite 作品集设计

## 目标

将现有 vinext 作品集重构为轻量 React + Vite 网站，优先服务桌面端求职展示，同时保证手机端快速、清晰、可操作。第一版使用媒体占位，后续可以直接补充视频、图片、真实项目内容与联系方式。

## 信息架构

- 首页采用单页叙事：全屏 Hero、个人介绍、精选作品、设计决策互动实验、AI 观点、联系方式。
- 三个案例保留独立路径：`/work/consumer`、`/work/enterprise`、`/work/campaign`。
- 导航包含 XZY、作品、关于、互动实验、联系；案例页导航返回首页对应区块。

## 视觉与布局

- 方向为电影感、编辑式、内容优先；基础版使用近黑画布、暖白文字和单一薄荷色强调。
- 内容版心最大宽度 `1700px`，桌面左右安全边距最小 `40px`，移动端边距 `20px`。
- Hero 高度 `100dvh`，桌面可按环境变量加载视频；没有素材时显示动态占位。手机端和节省流量模式不加载视频。
- 项目区使用不对称网格，C 端为主案例；小于 `768px` 后严格单列。

## 互动体验

“设计决策实验室”提供用户价值、业务价值、实现成本三个范围控件。纯函数根据输入输出“用户优先、商业聚焦、平衡推进、缩小范围”四类策略，支持鼠标、触屏与键盘，无持久化数据。

## 技术与性能

- React 19、Vite、JavaScript/JSX、原生 CSS，不使用 Next.js、数据库、Cloudflare 本地运行器、Tailwind或动效库。
- 使用浏览器路径判断渲染首页或案例页，不增加路由依赖。
- 系统字体、无外部字体请求；动效仅使用 transform 与 opacity，并尊重 `prefers-reduced-motion`。
- Node 内置测试覆盖内容数据、决策算法与真实 React 服务端渲染；Vite 构建作为发布门槛。

# XUE STUDIO 花朵开屏动画设计

## 目标

用一段简短、可跳过的花朵开屏强化 `DESIGN IN BLOOM` 的品牌记忆点，并通过花朵剪影自然过渡到现有首页。开屏不得延迟招聘方浏览作品，不得破坏首页蜂群、花束点击、落花物理、导航或案例入口。

## 播放规则

- 开屏仅在当前浏览会话首次进入首页时播放。
- 使用 `sessionStorage` 记录已完成状态；从案例页返回首页不重复播放。
- 刷新当前标签页仍沿用当前会话状态，不重复播放；关闭标签页后重新打开可再次播放。
- 开屏出现后无需等待动画结束，用户可立即点击中心花朵进入首页。
- 键盘用户可用 `Enter` 或 `Space` 触发；花朵提供明确的无障碍名称。
- 若素材或遮罩能力不可用，直接淡入首页，绝不阻塞页面。

## 视觉与节奏

### 初始画面

- 背景沿用网站暖米色 `#f7f6f2`，覆盖整个视口。
- 页面加载后保留约 `300ms` 的安静空白。
- 一朵与现有首页视觉语言一致的黑白花朵从中心弹出。
- 花朵采用快速弹簧进入：约 `600ms`，带轻微过冲，不使用夸张弹跳。
- 稳定后进行缓慢、不完全匀速的旋转，避免机械感。
- 花朵下方显示小号提示 `点击绽放`，不抢夺主体视觉。

### 点击反馈与揭示

- 指针按下时花朵立即缩小约 `8%`，形成直接反馈。
- 释放后花朵快速回弹并持续放大。
- 放大的花朵轮廓作为揭示遮罩，首页从花朵内部出现。
- 遮罩扩张约 `700–900ms`，使用强 `ease-out`；首页不做额外大幅位移动画。
- 遮罩覆盖视口后，开屏层完全卸载，避免透明层继续拦截点击。
- 首页中心花束保持原位置和现有交互，不在转场结束时瞬移。

## 组件边界

新增独立的 `OpeningBloom` 组件：

- 负责会话判断、开屏状态、输入事件、遮罩进度和卸载。
- 接收 `flowerSrc`、`storageKey`、`onComplete` 等简单参数。
- 不读取或修改 `BeeSwarmHero`、Matter 花朵记录或蜂群状态。
- 作为首页内容上方的固定覆盖层渲染；首页本身可在背景中完成布局，避免揭示时重新排版。

状态依次为：

1. `idle`：米色空屏。
2. `arriving`：花朵弹出。
3. `ready`：花朵缓慢旋转，等待输入。
4. `revealing`：花朵放大并揭示首页。
5. `complete`：写入会话标记并卸载开屏层。

重复点击在 `revealing` 状态下忽略，确保动画不会重启或频闪。

## 遮罩方案

首选 CSS `clip-path`/遮罩层方案：用花朵透明素材的轮廓驱动视觉揭示，同时仅动画 `transform` 与 `opacity`。若实际素材的透明轮廓无法产生清晰剪影，则使用内嵌 SVG 花朵路径作为遮罩，首页花朵素材仍保持不变。

不采用整张花朵图片简单铺满屏幕，因为那会变成黑色图片遮挡，而不是“透过花朵进入网站”。

## 输入与可访问性

- 中心花朵是可聚焦按钮，标签为 `点击花朵进入 XUE STUDIO`。
- 鼠标、触摸、Enter、Space 使用同一触发流程。
- 点击空白区域不触发，保持动作与花朵之间的因果关系。
- `prefers-reduced-motion: reduce` 下不旋转、不缩放穿越，仅以约 `200ms` 交叉淡入首页。
- 开屏激活时锁定页面滚动；完成或组件卸载时恢复原有滚动状态。
- 焦点在完成后移动到首页主内容或保留在自然文档顺序中，不落到已卸载元素。

## 性能与容错

- 复用本地透明花朵素材，不请求远程资源，不新增 npm 依赖。
- 仅动画合成层属性，避免逐帧 React state 更新。
- 使用一次性事件和定时器，并在卸载时全部清理。
- 页面不可见时不启动旋转；恢复后从当前状态继续。
- `sessionStorage` 访问包裹在容错逻辑中，隐私模式或存储异常时仍可正常进入首页。

## 测试与验收

- 首次会话渲染开屏，已有会话标记时直接显示首页。
- 点击、Enter、Space 均只触发一次揭示。
- 揭示完成后写入会话标记并卸载覆盖层。
- 重复点击不会重启动画。
- reduced-motion 路径不包含旋转和大幅缩放。
- 素材加载失败或存储不可用时可立即进入首页。
- 首页原有花束、蜂群、落花、拖动、10 秒消散、导航与作品入口全部保留。
- 在桌面与手机尺寸检查遮罩始终覆盖完整视口，无闪白、滚动条跳动或残留点击层。
- 运行 `npm test`、`npm run build` 和本地浏览器交互验收。

## 明确不包含

- 不加入声音、震动或自动播放视频。
- 不改变首页花束、蜜蜂和项目内容的视觉设计。
- 不在每次路由切换时重复开屏。
- 不部署公网。
